# Kinetic Stand Control System (Arduino Mega)

Программное обеспечение для управления декоративным кинетическим стендом на базе Arduino (Mega 2560). Стенд приводится в движение четырьмя сервоприводами постоянного вращения (360°) и оснащен статической LED-подсветкой.

## 📌 Описание работы
Стенд работает в автономном режиме, циклично выбирая одну из 4 заложенных программ движения. Каждая программа представляет собой уникальную хореографию: от плавных перекатов до резких пульсирующих бросков. Смена программ происходит после глобальной паузы.

## 🔌 Схема подключения (Pinout)

| Компонент | Назначение | Пин Arduino | Примечание |
| :--- | :--- | :--- | :--- |
| **Top Left Motor** | Вертикальная ось (левый) | `D5` | PWM |
| **Top Right Motor** | Вертикальная ось (правый) | `D2` | PWM |
| **Horiz Right Motor**| Горизонтальная ось (правый)| `D3` | PWM |
| **Horiz Left Motor** | Горизонтальная ось (левый) | `D4` | PWM |
| **Light 1** | Основная подсветка 1 | `D9` | Светит постоянно (`HIGH`) |
| **Light 2** | Основная подсветка 2 | `D10` | Светит постоянно (`HIGH`) |
| **LED Finish** | Индикатор работы цикла | `D12` | Цифровой выход |
| **Random Seed** | Генератор энтропии | `A0...A6`| Пины для сбора аналогового шума |

## ⚙️ Технические решения (Архитектура)

### 1. Управление скоростью сервоприводов 360°
Поскольку используются сервоприводы постоянного вращения, отправка значений угла (от 0 до 180) через библиотеку `<Servo.h>` управляет не позицией, а **скоростью и направлением**:
*   `90` — точка полной остановки (`stopSpeed`).
*   `< 90` — вращение вперед/вверх.
*   `> 90` — вращение назад/вниз.

Для горизонтальных моторов применяется функция `calcSpeed()`, которая умножает дельту скорости на коэффициент `globalSpeedMultiplier`. Это позволяет замедлять или ускорять весь стенд, не ломая векторы направлений.

### 2. Плавный старт (LERP и S-кривые)
Для предотвращения резких рывков механики движения разделены на два типа:
*   **Горизонтальная ось (LERP):** Использует линейную интерполяцию (`moveSmoothly`) для разгона и торможения за строго отведенное время.
*   **Вертикальная ось (S-Curve):** Использует кинематическую кривую плавности (`smartRampTop` по формуле $3p^2 - 2p^3$). Это обеспечивает максимально мягкий старт и остановку тяжелой каретки, имитируя естественную инерцию.

### 3. Компенсация слабины (Точки натяга)
Вместо жестких рывков при старте вертикальных моторов реализована система выборки слабины. Перед началом S-образного разгона моторы мгновенно переходят в преднатяг (`upTension = 71` или `downTension = 118`), натягивают тросы в течение 50 мс, и только после этого начинают плавный разгон до рабочей скорости.

## 🛠 Известные ограничения и хаки

*   **Открытая петля управления (Езда вслепую):** В системе нет энкодеров или концевых выключателей. Позиционирование осуществляется исключительно по таймерам. Из-за этого при длительной работе возможно накопление физической ошибки позиционирования каретки.
*   **Генерация случайных чисел:** Чтобы стенд не повторял программы в одном и том же порядке после каждой перезагрузки по питанию, `randomSeed` инициализируется суммой аналоговых шумов, собранных с висящих в воздухе пинов `A0–A6`.
*   **Защита от двойных программ:** Чтобы случайный выбор не выдал одну и ту же хореографию дважды подряд, реализован цикл проверки, принудительно перебрасывающий кубик, если выпала предыдущая программа.

## 🚀 Хореография (Сценарии)
1.  **Базовая:** Плавные, симметричные горизонтальные проезды туда-сюда на полной амплитуде, затем плавный вертикальный подъем и спуск.
2.  **Реверсивная:** Сначала отрабатывает вертикаль, затем следуют горизонтальные проезды.
3.  **Ускоренная:** Аналог первой программы, но время разгонов и пауз искусственно сокращено вдвое.
4.  **«Пульс»:** Движение вперед осуществляется тремя короткими рывками, после чего следует вертикальная фаза и единый, удлиненный возврат назад.
